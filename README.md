# Manzel H

محرك ويب عربي لتحويل مخطط 2D إلى نموذج هندسي 3D قابل للمراجعة، ثم إضافة هوية معمارية سعودية فوق هندسة ثابتة.

## الفكرة الأساسية

المشروع لا يعتمد على توليد صورة جميلة ثم اعتبارها منزلاً دقيقاً. المسار هو:

```text
صورة المخطط
→ معايرة مقياس حقيقي
→ استخراج الجدران
→ توحيد المقاطع Canonicalization
→ اقتراح فجوات الأبواب والنوافذ
→ اكتشاف الغرف المغلقة وحساب مساحاتها
→ مراجعة بشرية
→ بناء 3D
→ إضافة الطراز والخامات والسور والسقف
```

الهندسة هي المصدر الحقيقي، بينما الطراز البصري لا يغيّر المقاسات المعتمدة.

## الموجود الآن في Reconstruction Engine V3

- رفع صورة مخطط أو PDF (الصفحة الأولى تُحوّل إلى Raster عالي الدقة).
- معايرة متعددة القياسات مع Median robust scale وقياس اختلاف الأدلة.
- اقتراح الجدران من الصورة داخل المتصفح.
- توحيد المقاطع المتجاورة إلى جدران Canonical.
- اقتراح فجوات أبواب/نوافذ من الانقطاعات بين المقاطع.
- إضافة/حذف الجدران والفتحات يدوياً.\n- إغلاق Near-miss intersections تلقائياً لتحسين اكتشاف الغرف.\n- تحديد أي جدار وتعديل طوله وسماكته بدقة 0.001 م.\n- عرض أبعاد الجدران الحقيقية مباشرة فوق المخطط.
- ربط كل باب ونافذة بالجدار المضيف.
- فتحات حقيقية في الجدار ثلاثي الأبعاد.
- اكتشاف المساحات المغلقة من topology الجدران.
- حساب مساحة كل غرفة بالمتر المربع.
- إعادة تسمية الغرف.
- تصنيف أولي للجدران الخارجية.
- أرضيات مستقلة لكل مساحة مكتشفة.
- سقف داخلي اختياري وسطح خارجي.
- أربعة قوالب بصرية أولية: سعودي حديث، نجدي حديث، حجازي حديث، Minimal دافئ.
- سور خارجي وبوابة وتهيئة موقع أولية.
- فحص هندسي للمشاكل الأساسية قبل اعتماد 3D.
- حفظ تلقائي محلي.
- تصدير/استيراد مشروع JSON v3 مع صورة المصدر.
- PWA قابلة للتثبيت والعمل دون اتصال بعد أول تحميل.\n- تصدير النموذج الحالي كملف GLB.\n- محلل FastAPI + OpenCV اختياري للمخططات المعقدة مع fallback محلي في المتصفح.\n- CI يبني الواجهة ويتحقق من Syntax خدمة التحليل عند كل Pull Request وPush.

## ما الذي يعتبر "دقيقاً"؟

الدقة لا تعني التشابه البصري فقط. إذا تمت معايرة المخطط ثم اعتماد جدار بطول 4.20 م، يجب أن يبقى طوله الهندسي 4.20 م في النموذج.

لذلك:
- كل استخراج تلقائي هو **اقتراح** حتى تتم مراجعته.
- لا يتم وصف نتيجة غير مراجعة بأنها مطابقة بالمليمتر.
- كشف الغرف الحالي مخصص أساساً للمخططات المتعامدة orthogonal، ويحتاج توسعة مستقلة للمخططات كثيرة الجدران المائلة.

## ما تبقى للوصول إلى منتج معماري متقدم

- OCR للأبعاد وأسماء الغرف من الصور وملفات PDF.
- Analyzer خادمي للمخططات المعقدة بدلاً من الاعتماد على المتصفح فقط.
- اكتشاف أفضل لسماكات الجدران.
- أبواب بأقواس فتح وأنواع متعددة.
- سلالم وأعمدة وعناصر إنشائية.
- أكثر من طابق.
- مكتبة أثاث ونماذج GLB واقعية.
- تصدير GLB/glTF.
- نظام واجهات سعودي أكثر تفصيلاً يفصل الواجهة عن مخطط الدور.
- Benchmark على مجموعة مخططات حقيقية مع Ground Truth.

## مراجع معمارية تمت دراستها

- `FeniXb3/open3dFloorplan` — محرر 2D/3D حديث بترخيص MIT.
- `furnishup/blueprint3d` — مرجع مهم لفصل نموذج المخطط عن عارض Three.js.
- تجربة `Malik05255/manzl_3D` — خصوصاً فصل Analyzer عن Canonical geometry ومراجعة العناصر منخفضة الثقة.

لم يتم نسخ كود هذه المشاريع إلى المستودع؛ تم الاستفادة من أفكارها المعمارية مع تنفيذ مستقل.

## تشغيل المحلل الاختياري

```bash
cd services/analyzer
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

ثم في الواجهة:

```bash
VITE_ANALYZER_URL=http://localhost:8000 npm run dev
```

عند نشر المحلل على نطاق مختلف اضبط `ALLOWED_ORIGIN` على رابط الواجهة. إذا لم يتم ضبط `VITE_ANALYZER_URL` تستمر الواجهة باستخدام التحليل المحلي تلقائياً.
