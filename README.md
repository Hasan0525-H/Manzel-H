# Manzel H

محرك ويب لتحويل المخطط 2D إلى نموذج هندسي 3D قابل للمراجعة، مع هدف نهائي: منزل سعودي كامل مع الحفاظ على أبعاد المخطط بدل الاعتماد على تخمين توليدي.

## لماذا هذا المسار مختلف؟

المشروع يفصل بين مرحلتين:

1. **الهندسة أولاً**: معايرة المقياس، استخراج/مراجعة الجدران، ثم حفظ الإحداثيات بوحدات حقيقية.
2. **التجميل لاحقاً**: الطراز، الخامات، الأثاث، الواجهات والإضاءة لا يسمح لها بتغيير هندسة المخطط المعتمدة.

هذا يمنع المشكلة الشائعة في حلول image-to-3D التي تعطي شكلاً جميلاً لكن بأبعاد غير موثوقة.

## الموجود الآن

- رفع صورة مخطط من الجهاز.
- معايرة القياس بنقطتين وبُعد معروف.
- اقتراح جدران من الصورة داخل المتصفح.
- إضافة جدران يدوياً مع Snap.
- حذف الجدار بالنقر المزدوج.
- معاينة 3D مباشرة بـ Three.js.
- ارتفاع وسماكة جدران قابلة للتعديل.
- قوالب شكل أولية: سعودي حديث، نجدي حديث، حجازي حديث، Minimal دافئ.
- عرض 2D و3D أو العرض المزدوج.
- تصدير Canonical JSON بوحدات المتر.
- واجهة عربية Responsive.
- CI يبني المشروع عند كل Push/PR.

> اقتراح الجدران الحالي **Proposal engine** وليس اعتماداً نهائياً. المطلوب أن يراجع المستخدم الهندسة قبل اعتبارها بالمليمتر.

## الاتجاه الهندسي

تمت مراجعة أفكار ومشاريع مفتوحة المصدر في مساحة محررات المخططات، ومنها:

- `FeniXb3/open3dFloorplan` — محرر 2D/3D حديث بترخيص MIT.
- `furnishup/blueprint3d` — مرجع قديم ومهم لفصل نموذج المخطط عن عارض Three.js.
- تجربة `Malik05255/manzl_3D` السابقة — خصوصاً فصل الـAnalyzer عن الـCanonical geometry ومراجعة العناصر منخفضة الثقة.

لا يعتمد هذا المستودع على نسخ كود تلك المشاريع؛ تم استخدام مبادئها المعمارية مع تنفيذ جديد وخفيف.

## الخطة التالية

### P1 — Reconstruction Core
- تحسين دمج المقاطع المكتشفة إلى centerlines حقيقية.
- اكتشاف سماكة الجدران بدلاً من قيمة ثابتة.
- اكتشاف الأبواب والنوافذ وربط كل فتحة بجدارها.
- اكتشاف الغرف من topology المغلق.
- شاشة مراجعة Confidence قبل 3D.

### P2 — Exact Geometry
- Dimension evidence من خطوط القياس والنص.
- معايرة متعددة النقاط واكتشاف التعارض.
- Canonicalization هندسية.
- قياسات رقمية بالسنتيمتر/المليمتر.
- Validator يمنع الغرف المفتوحة أو التقاطعات غير الصالحة.

### P3 — Saudi Building System
- مكتبة واجهات سعودية مستقلة عن هندسة المخطط.
- أسوار، بوابات، مداخل، مظلات، أسطح، درابزين ونوافذ.
- قوالب سعودي حديث / نجدي / حجازي.
- توزيع مواد وإضاءة وبيئة خارجية.
- GLB/glTF export.

### P4 — Product
- حفظ المشاريع والإصدارات.
- PWA ثم تغليف Android بعد استقرار الويب.
- مقارنة Overlay بين المصدر والـVector.
- Benchmark على مخططات حقيقية قبل وصف الناتج بأنه دقيق.
